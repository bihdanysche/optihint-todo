# To-Do List

Список завдань, створений за допомогою Next.js, React, TypeScript та Tailwind CSS.

## Функціональність

- Додавання, видалення та відмітка виконання завдань.
- Редагування завдань подвійним кліком.
- Відображення кількості невиконаних завдань.
- Збереження та відновлення даних через localStorage.
- Індикація завантаження даних.
- Адаптивний інтерфейс із hover-ефектами.

## Встановіть залежності:

```bash
npm install
```

## Запуск у режимі розробки

```bash
npm run dev
```

## Запуск у продакшн режимі

```bash
npm run build
npm run start
```

Відкрийте http://localhost:3000.

## Можливі покращення

- Фільтрація за статусом виконання.
